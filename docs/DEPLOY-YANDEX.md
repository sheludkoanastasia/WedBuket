# Деплой фронта WedBuket на Yandex Object Storage

Сборка: `npm run build` → папка `dist/`.  
CLI `yc` / `aws` пока не обязательны — первый раз удобно через консоль.

## 1. Собрать сайт

```bash
npm run build
```

В `.env` должен быть:
```
VITE_API_URL=https://functions.yandexcloud.net/d4ett7rjr5uh3sdj41ro
```

## 2. Создать бакет (консоль)

1. [console.yandex.cloud](https://console.yandex.cloud) → ваш каталог  
2. **Object Storage** → **Создать бакет**  
3. Имя (глобально уникальное), например: `wedbuket-site-<ваши-инициалы>`  
4. Доступ: можно **ограниченный**, публичность настроим ниже  
5. Класс хранения: стандартный  

Запомните **имя бакета**.

## 3. Публичный доступ на чтение

В бакете:

1. **Права доступа** / ACL → разрешить **публичное чтение объектов**  
   (или политика: `AllUsers` → `storage.objectViewer` на объекты)  
2. Без этого сайт не откроется в браузере.

## 4. Загрузить `dist`

1. Откройте бакет → **Загрузить объекты**  
2. Загрузите **всё содержимое** `dist/` в **корень** бакета:
   - `index.html`
   - папка `assets/`
   - остальные файлы из `dist` (favicon и т.д.)  
3. Не кладите папку `dist` целиком как один каталог `dist/index.html` — нужен именно корень: `/index.html`.

В консоли часто удобнее перетащить файлы и папку `assets`.

## 5. Статический хостинг (SPA)

В настройках бакета найдите **Веб-сайт** / **Хостинг статического сайта**:

| Параметр | Значение |
|----------|----------|
| Индексный документ | `index.html` |
| Документ ошибки | `index.html` |

Документ ошибки = `index.html` нужен для маршрутов `/sitemap`, `/privacy`, `/terms`.

После включения появится **website endpoint**, вида:

```text
https://<bucket>.website.yandexcloud.net
```

или

```text
http://<bucket>.website.yandexcloud.net
```

(точный вид смотрите в консоли)

Откройте этот URL — должен открыться WedBuket.

## 6. Проверка

- [ ] Главная открывается  
- [ ] Календарь грузит даты (запрос к Cloud Function)  
- [ ] `/sitemap` открывается (не 404)  
- [ ] Форма брони работает  

Если календарь пустой / CORS — функция должна быть публичной (у вас уже так).

## 7. Обновление сайта позже

Снова:

```bash
npm run build
```

Удалите старые объекты в бакете (или перезапишите) и загрузите новый `dist`.

Когда установите [AWS CLI](https://docs.aws.amazon.com/cli/) (совместим с Yandex) — можно использовать `scripts/deploy-yandex.ps1`.

## 8. Vercel

После того как Yandex-URL работает — деплой на Vercel можно отключить. GitHub push сам по себе бакет не обновит.

## Имя бакета

Запишите сюда после создания:

```text
BUCKET=
WEBSITE_URL=
```
